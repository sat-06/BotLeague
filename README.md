# 🤖 BotLeague

BotLeague is a modern and responsive landing page designed for a robotics competition event. It provides participants with all the essential event information through an engaging interface, including competition categories, event timeline, robotics disciplines, sponsor details, and registration information.

Built with **React**, **TypeScript**, and **Vite**, the project emphasizes clean UI, responsiveness, and a smooth user experience across devices.

---

## ✨ Features

- 🎯 Modern and responsive UI
- ⚛️ Built with React + TypeScript
- 🚀 Powered by Vite for fast development
- 📱 Fully mobile-friendly design
- 🧩 Component-based architecture
- 🤖 Dedicated sections for:
  - Hero Banner
  - Competition Categories
  - About Event
  - Event Timeline
  - Robotics Disciplines
  - Why Register
  - Sponsors
  - Registration Call-to-Action
  - Footer

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/your-username/BotLeague.git

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open **http://localhost:5173** in your browser.

## 📦 Build

```bash

```

## 🎯 Use Case

BotLeague serves as a promotional website for robotics competitions, college technical festivals, hackathons, and similar technology events. It presents event details in a visually appealing and user-friendly manner while encouraging participant registrations.
